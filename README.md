# Тест pandas для Toolbox ARM

Маленькое приложение, чтобы проверить установку и запуск инструмента из git
через Toolbox ARM (`download.type: bitbucket`, `launch.type: bat`).

- `requirements.txt` — pandas и openpyxl: батник ставит их в venv при первом запуске.
- `main.py` — печатает ход работы и итог по отделам, затем открывает окно с
  таблицей. Закрыли окно — программа завершилась.

Запуск вручную: `python main.py`.
